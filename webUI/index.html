1. 选择 CSV 工作负载

按配置选择 .co 和完整测试参数。同一 .co 的不同尺寸分别创建任务。操作在 Web UI 所在的环境执行；远端任务通过本机快照展示。

2. 导出 seed、验证原始代码、创建调优任务

原始数值和正常入口派发验证通过后再调优。MNK、splitK、layout 和 manifest 使用所选 workload，不能在这里改写。

3. 执行持久化调优步骤

创建任务只冻结输入。先 eval original，然后 observe / suggest / prepare / eval，最后 confirm / final。agent 按 aiter 和 MFMA skill 提出候选。

prepare 候选参数
高级：SDK agent 调优入口

选择计划中的 aiter workload，或手动填写其他 client 与 seed，启动本地 Cursor agent。自动加载所选 client 与架构技能；填写配对策略后执行逐指标确认和最终复测，留空则只筛选。aiter 最终获胜候选自动保存到 co_out、追加 README 并提交推送 Git；关联尺寸采用按 client 技能继续验收。

4. 固定候选，单尺寸验证与配对比较
